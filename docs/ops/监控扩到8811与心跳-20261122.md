# 监控扩到 8811 + 心跳留痕（2026-11-22 16:12）

## 一、guard 是否真在定时跑（证明「常驻」不是「加载了」）

```
launchctl print gui/501/com.wuwu.wuwu-living-guard
→ state = not running        ← StartInterval 型任务的正常态
→ run interval = 300 seconds
→ runs = 1  last exit code = 0
```

**手动触发验证它能被拉起：**
```
launchctl kickstart gui/501/com.wuwu.wuwu-living-guard
触发前: runs=1  状态文件=16:02:04
触发后: runs=2  状态文件=16:02:42
✅ runs 涨了、状态文件被重写 ⇒ launchd 真能拉起它
```

★ 判它活没活，看 **runs 涨不涨 + 状态文件 mtime**，不看 `state`。

## 二、把 8811 并入同一个 guard（补盲区）

之前 guard 只盯 8890 客厅，**8811 音乐房是盲区**——今天它反复崩溃、端口在听却不回包，一度全组无人发现。

并入方式（`ops-guard.sh`）：
```bash
OUT8811="$(bash "$DIR/scripts/ops-8811.sh" -n 10 -t 4 2>&1)"
RC8811=$?
if [ "$RC8811" -ne 0 ]; then
  OUT="$OUT
  FAIL  音乐房8811      $(...摘出 HUNG/DEAD/DEGRADED...)"
  [ "$RC" -eq 0 ] && RC=1     # 8811 故障不抬到 2（客厅才是入口），但状态要变 bad
fi
```

**关键设计**：8811 挂了不把整体判成 FAIL(2)，只判 DEGRADED(1)。
理由：客厅 8890 是用户唯一入口，8811 是其中一个房间——房间坏了要告警，但不该让入口级判据失真。

### 负向臂（真停 8811）
```
launchctl bootout gui/501/com.wuwu.lingting.web
8811 → code=000

guard 输出：
  PASS  入口存活        3/3 200          ← 客厅正常
  PASS  托管项存在      pid=21920        ← 客厅正常
  PASS  实验实例隔离    1 个全部合规
  FAIL  音乐房8811      DEAD  0/10（毫秒级 RST，无进程接）   ← 抓到了

EXIT=1
告警日志：ALERT rc=1 cnt=1  FAIL  音乐房8811  DEAD  0/10
```

**客厅三项全 PASS、8811 单独报 DEAD** —— 这正是「两个服务分别判」的价值。
恢复后：`pid=23493`、3/3 200、推 `RECOVERED`。

## 三、修掉「静默成功」（比崩溃更危险）

**问题**：正常时 guard 什么都不打印，`/tmp/wuwu-living-guard.log` 是空文件。
于是 **无法区分「跑过了、没发现问题」和「根本没跑」**——这和今天 8890 掉线十几分钟无人发现是同一类盲区。

**修法**：正常时也打一行心跳
```
16:03:51  OK  8890=1  8811=1
```

**验证**：`launchctl kickstart` 后日志出现该行、`runs` 从 3 涨到 4。

## 四、最终五臂验收（退出码均不接管道取）

```
臂1 两侧健康            → EXIT=0  ALERT=0（不推假告警）
臂2 8890 死（PORT=9）   → EXIT=2  ALERT=1
臂3 连续故障 6 次       → 累计 ALERT=3（cnt 1/3/6，去重生效）
臂4 故障→恢复           → RECOVERED=1
臂5 恢复后再跑 2 次     → RECOVERED 仍为 1（幂等）
```

## 八、遗留
1. **告警只到 macOS 通知中心**，用户不在电脑前收不到。要推到手机/飞书得接 `de_notify` 或 webhook。
2. guard 每 300s 一次，**最坏要 5 分钟才发现故障**。入口级故障若要更快，可把 `StartInterval` 降到 60s（代价是每分钟一次 curl）。
3. 8811 的 `ops-8811.sh` 用 10 次采样，比客厅的 3 次慢；若嫌 guard 单次耗时太长可降到 5 次。
