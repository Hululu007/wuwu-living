## 一、探针

`~/D盘/product-method/room-page-probe.mjs`

真 Chrome（headless）+ CDP 逐间房量五项，不用 curl 数 DOM：

| 项 | 判据 |
|---|---|
| 入口唯一性 | 「回首页」语义元素的 total / visible（走 `getComputedStyle` + 祖先链 + rect） |
| 零尺寸控件 | 可点击元素 rect 宽或高为 0，**排除隐藏树内的** |
| 横向溢出 | `scrollWidth - innerWidth > 0` |
| 破图 | `naturalWidth === 0` 且**真的声明了 src** |
| 请求失败 / JS 异常 | 忽略 favicon |

```bash
node ~/D盘/product-method/room-page-probe.mjs          # 十间房
node room-page-probe.mjs --json                        # 明细
node room-page-probe.mjs --base=URL --rooms=good.html  # 对夹具跑臂
```

退出码三态：`0` 全绿 / `1` 测出缺陷 / `2` 探针故障（**不能算通过**）。

### 四臂自证（缺一就等于没测）

| 臂 | 命令 | 期望 | 实测 |
|---|---|---|---|
| 正向 | `--rooms=good.html` | exit=0 | ✅ exit=0 |
| 负向 | `--rooms=bad.html`（藏入口+零宽按钮+破图） | exit=1 且报出四项 | ✅ exit=1，四项全报 |
| 幂等 | good 连跑两次 | 输出一致 | ✅ true |
| 故障 | `--base=http://127.0.0.1:9` | exit=2 且标「探针故障」 | ✅ exit=2 |

故障臂是最关键的一条：第一版它对黑洞端口报 `exit=1 有问题 1 间`——**把探针自己挂了当成产品有缺陷**，正是总管说的「因为出错而红」。改用 Navigation Timing 的 `responseStatus`（0 = 导航失败）才分开。

## 三、真缺陷：`/magnet/` 与 `/vod/` 返回入口 = 0

### 症状
截图 `shots/magnet.png`：页面顶部只有它自己的「搜磁力」栏，**没有任何回客厅的入口**。用户只能靠浏览器后退。

### 根因：双向隐藏
1. 上游自己带一条规则把客厅注入的顶栏藏掉：
   - `~/D盘/magnet-search/server.mjs:659`
     `html body[data-room="magnet"].ww-shell .ww-bar{display:none!important}`
   - `~/D盘/项目/请看/public/index.html:97`
     `html body[data-room="vod"].ww-shell .ww-bar{display:none!important}`
2. 客厅的 `lib/legacy_shell.mjs:90-102`（`dupHomeCss`）为了「只允许一个返回语义」，
   把上游自己的 `.mx-home` / `#homeLink` 一起 `display:none!important`。

**两条规则各自都对，叠在一起就两头都藏 ⇒ 可见入口 0。**

### 实测证据（CDP，不改文件）
```
删掉上游那条 .ww-bar{display:none} 后：
/magnet/  visible 0 → 1   （81×28，文字「回客厅」）
/vod/     visible 0 → 1   （81×28）
```

### 修法（已注入验证，未落盘）
在 `lib/legacy_shell.mjs` 的 `dupHomeCss` 里追加一条同优先级但命中范围更准的规则，
让顶栏在这两间房重新显示——**不动上游任何文件**：

```css
html body[data-room="magnet"].ww-shell .ww-bar,
html body[data-room="vod"].ww-shell .ww-bar{ display:flex!important; }
```

注入后实测：`/magnet/` 顶栏 `display:flex`、rect 1440×46；`/vod/` 同样恢复，
且**两间房可见入口数都恰好 = 1**（上游那个仍被 dedup 收起，没有变回「两个返回」）。

### 为什么不是直接删上游那条
上游是别人的项目目录（`magnet-search` / `请看`），删了下次它自己更新就回来；
在客厅侧加一条覆盖规则，责任边界清楚，也符合「只改自己负责的文件」。

### 回滚
修法只加 CSS 行，回滚＝删掉那三行；或
`git -C ~/D盘/项目/五五客厅 checkout lib/legacy_shell.mjs`
