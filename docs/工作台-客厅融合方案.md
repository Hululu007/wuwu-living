## 0. 结论先行（四句）

1. **书房 = 远程 iframe**，指向 `http://<电脑IP>:8890/book/`；手机跑不了 Node，这是唯一可行路径。

## 2. 源码真相与施工基座（必须先厘清，否则改错文件）

实测两份目录的关系不是「新旧版本」，而是「**完整树 vs 覆盖包**」：

| 目录 | 内容 | app.js | 说明 |
|---|---|---|---|
| `~/D盘/项目/workbench-src/app/src/main/assets` | **完整源码树**：`app.css`(13,363B)、`app.js`(227,669B)、`index.html`、`music/`、`data/`（含 magnet-sources.js）、Java 源 + Manifest + `构建APK.cmd` | 227,669B（旧） | 这是能 `gradlew` 出包的全量工程 |
| `~/D盘/项目/workbench-upgrade/vod-update-20261116` | **覆盖包（vod 升级批次）**：`app.js`(438,183B)、`index.html`、`assets/hls.min.js`(388,933B)、`assets/vod.js`(50,792B)、`app.js.before`(436,145B)、`build/workbench-v8.34.0-vod-signed.apk` | 438,183B（最新） | 只有被改动的文件 + 出好的 APK，**没有 app.css / music / data / Java 源** |

**施工基座结论**：不能直接在 `vod-update-20261116` 上改（缺 app.css、music、data、Android 源，改完出不了包）。正确做法是——
1. 复制一份完整树做工作副本（例如 `~/D盘/项目/workbench-upgrade/d-lite-20261117/`），
2. 把覆盖包的 `app.js`(438KB) / `index.html` / `assets/hls.min.js` / `assets/vod.js` **盖进**副本的 `app/src/main/assets/`，
3. 与 `build/` 里已签名 APK 的 assets 逐文件比对 SHA，确认副本 == 手机上 v8.34.0 的内容，
4. 再在这份副本上改动，`app.js` 先备份成 `app.js.before`（覆盖包里已有同名备份，沿用这个命名习惯）。

**设备事实**：`adb devices` → `edfad25e device`（在线）；手机装 `com.wush.workbench` v8.32.0（versionCode 136）；出包产物 `workbench-v8.34.0-vod-signed.apk` 在覆盖包 `build/` 下。

## 3. 书房接入（D1）

### 3.1 形态
新增 `shufang` tab：`#view` 内一个**全屏 iframe**，`src = http://<客厅地址>:8890/book/`。理由：
- 工作台页面是 `file:///android_asset/index.html`，Origin=`null`，直接 `fetch` 客厅接口会被 CORS 拦死（`vod.js` 头部注释已记录同类坑，它靠 `AndroidStore.httpGet` 绕）；iframe 内页面自身同源，**零 CORS 改造**；
- 客厅书房内部是 `书房.html` + `/api/book/*` 同源相对路径，换 base 即通；
- 后续客厅加 token 时，只需 iframe 首屏带一次 `?k=`，同源 iframe 内自动延续。

### 3.2 设置项（「我的」里）
- `客厅地址`：文本输入 + 保存（落 `AndroidStore.set`，沿用 `vod.js` 的 `ST_KEY` 落盘模式，失败回退 `localStorage`）；
- 默认值：`http://10.18.246.60:8890`（本机当前 LAN IP，实测）；
- `扫描局域网`按钮：对 `10.18.246.0/24` 并发 `GET /api/ping`（超时 300ms、并发 32、总预算 6s），结果按延迟升序；点选即保存。**不用 mDNS/NSD**（路由器常屏蔽组播）。
- 备选输入：`100.125.115.107`（本机另一个 100.x 段，疑似内网穿透/Tailscale）——扫描扫不到 100.x 时允许手工填。

### 3.3 连不上时（不许白屏）
三态明确文案 + 两个按钮：
- 「客厅没回应」→ `地址是否正确 / 手机和电脑是否同一 WiFi / 客厅口令`；
- 按钮：`重试`、`扫描局域网`、`改用系统浏览器打开`。
判定方式：`iframe onload` 前 3s 内无 `load` 事件或 `load` 后 `iframe.contentWindow.length` 异常 → 视为失败（WebView 内无法可靠读跨域 iframe 内容，故用超时 + `onerror` 双判）。

### 3.4 前后端必须配合的三件事（客厅侧，我这边做）
| 项 | 现状（实测） | 必须改 |
|---|---|---|
| 监听地址 | plist `HOST=127.0.0.1`；`lsof` 显示 `127.0.0.1:8890` | 改 `0.0.0.0`，手机才连得上；改后按「state=running + lsof 真监听 + ping 200」三件套核验 |
| 鉴权 | **无**（全文无 token/cookie 会话） | 加极简口令 token（`/api/ping` 与 `assets/*` 白名单），否则同网段任何设备可读写客厅 |
| 帧白名单 | 无 CSP / 无 `X-Frame-Options` | 加 `frame-ancestors` 白名单（内网 + `file://`），否则 iframe 可能被拦 |

### 3.5 返回键
`MainActivity.onBackPressed`（旧树 431–440 行）已判 `canGoBack()`；但客厅是 SPA（URL 不变）→ `canGoBack()` 恒 false → 按一次直接退出 App。需加约定：**先 `evaluateJavascript("__wwBack && __wwBack()")`**，客厅返回 `true` 表示已消费（例如从阅读页回到搜索页），否则走原生逻辑。

## 4. 视频差距清单（D2：本地补，不 iframe）

### 4.1 实测对比

| 能力 | 工作台本地 `vod.js` | 客厅 `/vod/`（「请看」25,712B） | 结论 |
|---|---|---|---|

| 首页推荐 | `最新上线`（拉片单） | **无**（`推荐`/`榜单`/`分类` 计数全 0） | 本地领先，但要补「分类分区」 |

| 搜索 | 有（多源聚合） | 有（`搜索` 3 处） | 持平 |
| 详情 | 有（37 处 detail） | 有（`详情` 2 处） | 持平，本地更全 |
| 选集 | 有（`共 N 集 · 点了就直接全屏播放`） | **无**（`选集` 计数 0） | 本地领先 |
| 播放器 | hls.js+MSE、进度/倍速/全屏/音量、独立浮层不被 `render()` 重建 | hls.js（`hls` 12 处 / `m3u8` 5 处） | 持平，本地体验更完整 |

## 6. 视觉 token 草案（D4）

### 6.1 现状问题（实测）
- `app.css` 的 `:root` 已有一套底色体系：`--bg:#0b1020`、`--bg2:#0f1528`、`--card:#151c33`、`--card2:#1b2340`、`--line:#25304f`、`--txt:#e8edf9`、`--mut:#8b98b8`、`--acc:#6ea8fe`、`--acc2:#63e6be`、`--r:14px`；
- 但 `app.js` 里有大量**内联硬色**绕过 token：`#5c4a20 + #241f12`（棕色卡片，出现 ≥5 处）、`#2e4a5a + #16232a`（青灰卡片）、`#5a2e2e + #2a1618`（错误红卡）；
- 圆角混乱：`8px/9px/10px/12px/5px/2px` 混用（`app.js` 内统计）；
- `vod.js` 自成一套：`#6ea8fe / #8b98b8 / #e8edf9 / #25304f / #1b2340 / #63e6be / #ff7b72`（与 `:root` 基本同源，但未复用变量）。

### 6.2 定案 token（新增 `assets/theme.css`，在 `app.css` 之后加载）

```css
:root{
  /* 底色（沿用现值，不改观感底子） */
  --bg:#0b1020; --bg2:#0f1528; --card:#151c33; --card2:#1b2340;
  --line:#25304f; --txt:#e8edf9; --mut:#8b98b8; --dim:#5f6d8f;
  /* 语义色（去掉内联硬色，改走变量） */
  --ok:#63e6be; --warn:#ffcc66; --dang:#ff7b72; --info:#6ea8fe;
  /* 每个 tab 一个主色（只在标题点/选中态/图标底色用，不刷整卡） */
  --ac-today:#ffcc66; --ac-study:#6ea8fe; --ac-write:#b197fc;
  --ac-music:#f783ac; --ac-video:#6ea8fe; --ac-magnet:#63e6be;
  --ac-shufang:#c9a86a; --ac-task:#8b98b8; --ac-me:#8b98b8;
  /* 形状与节奏（一套，禁止再写混合值） */
  --r-card:14px; --r-inner:10px; --r-btn:10px; --r-pill:999px;
  --sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px; --sp-5:24px;
  --fs-cap:12px; --fs-sub:13px; --fs-body:15px; --fs-h2:18px; --fs-h1:22px;
  --shadow-card:0 2px 10px rgba(0,0,0,.28);
}
/* 例：棕色/青灰内联卡统一成「语义卡片」 */
.card-soft{background:var(--card2);border:1px solid var(--line);border-radius:var(--r-inner)}
.card-warn{background:color-mix(in srgb, var(--warn) 10%, var(--card));border:1px solid color-mix(in srgb, var(--warn) 30%, transparent)}
.card-dang{background:color-mix(in srgb, var(--dang) 10%, var(--card));border:1px solid color-mix(in srgb, var(--dang) 30%, transparent)}
```
